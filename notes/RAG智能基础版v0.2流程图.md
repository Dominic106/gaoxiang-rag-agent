# RAG 智能基础版 v0.2 流程图

说明：这个文件是新版本流程图，旧版 `RAG完整流程图.md` 保留不动。

## 总览

```mermaid
flowchart TD
    A["用户输入"] --> B["多问题拆分"]
    B --> C["逐个子问题处理"]
    C --> D["问题理解/类型识别"]
    D --> E["Query 增强"]
    E --> F["构造最多 3 个检索 Query"]

    F --> G1["第 1 次检索：向量 + BM25"]
    G1 --> H1["Query Embedding 缓存检查"]
    H1 --> I1{"缓存命中？"}
    I1 -->|是| J1["复用本地 Query 向量"]
    I1 -->|否| K1["调用豆包 Embedding API"]
    K1 --> L1["写入 embedding_query_cache.jsonl"]
    J1 --> M1["Chroma 向量检索"]
    L1 --> M1
    G1 --> N1["BM25 关键词检索"]
    M1 --> O["合并去重/重排"]
    N1 --> O

    O --> P["证据分计算"]
    P --> Q["核心术语覆盖率检查"]
    Q --> R{"证据足够？"}

    R -->|否，第 2 次| G2["第 2 次检索：仅 BM25 原问题"]
    G2 --> O
    R -->|否，第 3 次| G3["第 3 次检索：仅 BM25 核心关键词"]
    G3 --> O

    R -->|是| S["动态选择上下文数量"]
    S --> T["裁剪引用窗口"]
    T --> U["DeepSeek 保守回答"]
    U --> V["答案 + 引用依据"]

    R -->|三次仍不足| W["系统直接拒答"]
    W --> X["展示最接近原文片段"]

    V --> Y["保存问答报告"]
    X --> Y
    Y --> Z["写入会话历史"]
    Z --> AA["更新长期学习记忆"]
    AA --> AB["返回统一回复"]
```

## 离线建库阶段

```mermaid
flowchart LR
    A["208 个 Word 源文档"] --> B["读取段落和表格"]
    B --> C["文本清洗"]
    C --> D["章节/小节元数据识别"]
    D --> E["切分为 1125 个 chunk"]
    E --> F["保存 chunks.jsonl"]
    F --> G["建立 BM25 关键词索引"]
    F --> H["调用豆包 Embedding"]
    H --> I["生成文档向量"]
    I --> J["写入 Chroma 向量库"]
```

## 在线单问题查询

```mermaid
flowchart TD
    A["单个用户问题"] --> B["识别问题类型"]
    B --> C["扩展考试术语和同义词"]
    C --> D["第 1 轮：向量 + BM25"]
    D --> E["合并候选片段"]
    E --> F["证据评分"]
    F --> G{"是否达到证据阈值？"}
    G -->|是| H["裁剪必要上下文"]
    H --> I["DeepSeek 生成答案"]
    I --> J["返回答案和引用"]
    G -->|否| K["第 2/3 轮：仅 BM25 自救"]
    K --> E
    G -->|最终仍不足| L["保守拒答"]
    L --> M["返回检索日志和最接近片段"]
```

## 一次多个问题

```mermaid
flowchart TD
    A["用户一次输入多个问题"] --> B["按编号/换行/问号拆分"]

    C --> D["子问题 1"]
    C --> E["子问题 2"]

    E --> H["独立 RAG 查询"]
    F --> I["独立 RAG 查询"]
    G --> J["单题答案/拒答"]
    H --> K["单题答案/拒答"]
    I --> L["单题答案/拒答"]
    J --> M["统一汇总回复"]
    K --> M
    L --> M
    M --> N["保存 multi_rag_answer 报告"]
```

## 省钱机制

```mermaid
flowchart TD
    A["用户 Query"] --> B["生成缓存 Key：模型名 + 标准化文本"]
    B --> C{"embedding_query_cache.jsonl 有缓存？"}
    C -->|有| D["直接复用向量，不调用豆包 API"]
    C -->|没有| E["调用豆包 Embedding API"]
    E --> F["写入本地缓存"]
    F --> G["用于 Chroma 检索"]
    D --> G

    H["检索自救"] --> I["第 1 轮：向量 + BM25"]
    I --> J["如果证据不足"]
    J --> K["第 2 轮：仅 BM25"]
    K --> L["如果仍不足"]
    L --> M["第 3 轮：仅 BM25"]
```

## 防胡说机制

```mermaid
flowchart TD
    A["候选原文片段"] --> B["计算关键词命中分"]
    B --> C["抽取用户问题核心术语"]
    C --> D["计算核心术语覆盖率"]
    D --> E{"证据分和覆盖率达标？"}
    E -->|达标| F["允许调用 DeepSeek"]
    F --> G["DeepSeek 只能基于原文回答"]
    E -->|不达标| H["不调用 DeepSeek"]
    H --> I["直接返回知识库依据不足"]
    I --> J["附最接近原文和检索日志"]
```
