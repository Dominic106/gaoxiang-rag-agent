# 优化增强能力池

## 1. 文档定位

这里记录已经明确有价值、但当前没有承诺立即实施的优化方向。它们不是“当前待办”，也不代表项目已经缺功能，而是项目稳定后可以择机纳入版本规划的增强能力。

只有在明确目标、优先级、验收标准和实施窗口后，能力池中的项目才会转入 `docs/03_功能需求与验收标准.md`，成为正式待办或正式需求。

## 2. 与正式待办的区别

| 类型 | 含义 | 是否要求当前完成 |
| --- | --- | --- |
| 正式待办 | 已经承诺要做但尚未完成的事项 | 是 |
| 正式需求 | 已确定范围、验收标准和优先级的功能 | 按路线图实施 |
| 优化增强能力池 | 有价值但尚未承诺实施的改进方向 | 否 |
| 灵感记录 | 尚未验证价值的想法 | 否 |

本文件只保存“优化增强能力池”，不把它们写成“还差什么”，避免项目状态看起来总是没有完成。

## 3. 请求可靠性增强

| 增强项 | 价值 | 触发条件 |
| --- | --- | --- |
| 全链路总截止时间 | 限制多轮检索、重试和模型调用叠加后的最大等待时间 | 真实使用中出现等待过长 |
| 熔断与半开恢复 | 上游持续失败时暂时停止请求，恢复后自动探测 | API 服务频繁超时或限流 |
| 按异常类型分类重试 | 只对超时、连接失败、限流等临时错误重试 | 需要进一步降低无效重试 |
| 结构化 JSON 日志 | 便于按 request_id、错误类型和耗时统计 | 进入 Web UI 或需要长期运行 |
| 请求耗时与失败率看板 | 观察 DeepSeek、豆包和本地检索性能 | 出现性能优化需求 |
| 敏感信息自动脱敏测试 | 防止未来新增日志字段泄露 Key、提示词或教材隐私 | 日志字段继续扩展 |
| 幂等请求与重复提交保护 | 避免重试导致重复写会话、重复保存报告 | 接入 Web UI 或并发调用 |

## 4. 检索质量增强

| 增强项 | 价值 | 触发条件 |
| --- | --- | --- |
| 评估集扩展到 100 条以上 | 更可靠地评估不同章节、题型和拒答边界 | 核心查询继续优化 |
| 答案忠实度、引用准确率、拒答准确率 | 从“检索命中”扩展到“回答是否可信” | 需要量化回答质量 |
| 专业 reranker | 对 BM25 和向量候选进行更细粒度重排 | Hybrid Top1 出现明显瓶颈 |
| 多章节组合过滤 | 支持多个章节、知识域和排除条件 | 用户需要跨章节复习 |
| Query 改写质量评估 | 判断改写是否真正帮助检索，避免改写反而损失术语 | 检索自救命中率下降 |
| Chunk 版本化与索引对比 | 对比不同切分参数、embedding 模型和索引版本 | 需要频繁迭代建库 |

## 5. 学习体验增强

| 增强项 | 价值 | 触发条件 |
| --- | --- | --- |
| 跨会话学习主题恢复 | 让长期学习过程不依赖单个会话名 | 长期学习使用频率增加 |
| 错题本 | 保存错误理解、薄弱章节和复习状态 | 核心查询稳定后 |
| 复习卡片 | 将定义、区别、流程和公式整理为可重复复习内容 | 错题记录稳定后 |
| 薄弱点分析 | 按章节、题型和错误频率生成学习建议 | 累积足够学习记录后 |
| 考试模式 | 固定输出定义、考点、易混点、记忆法和原文依据 | 学习模板确定后 |
| 收藏与人工标注 | 允许用户标记重点、易错点和个人笔记 | Web UI 或交互 CLI 完善后 |

## 6. 产品化和工程增强

| 增强项 | 价值 | 触发条件 |
| --- | --- | --- |
| 本地 Web UI | 降低命令行使用门槛，提供引用查看和会话管理 | 核心 API 稳定、交互需求明确 |
| 并发安全与进程级资源管理 | 支持多个用户或多个请求同时查询 | 开始 Web UI 化 |
| 索引增量更新 | 只处理新增或变更文档，减少重建成本 | 教材版本经常更新 |
| 数据库迁移与备份 | 保护会话、学习记录和索引元数据 | 数据量和使用周期增加 |
| 配置中心 | 统一管理模型、超时、成本和检索参数 | 配置项明显增多 |
| 自动化发布与回归 | 每次代码变化自动执行核心测试 | 项目多人协作或长期运行 |

## 7. 进入正式待办的条件

能力池项目转正时必须补充：

1. 要解决的具体用户问题。
2. 输入、输出和异常行为。
3. 对 token、API 成本、延迟和本地资源的影响。
4. 对现有状态、数据格式和流程图的影响。
5. 最小验收用例和回归测试。
6. 明确优先级、版本号和是否暂停其他工作。

当前能力池不设“全部完成”目标，按实际学习效果和工程收益择机选择。
