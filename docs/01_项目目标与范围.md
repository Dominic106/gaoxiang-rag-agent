# 项目目标与范围

## 1. 项目初衷

把《信息系统项目管理师辅导教程第3版全版》整理成一个可检索、可引用、可持续学习的 RAG 知识库，帮助用户围绕教材学习、复习和定位原文依据。

项目的本质不是让大模型自由聊天，而是让系统先找到教材证据，再在证据范围内生成回答。

## 2. 当前目标

- 将 208 个 Word 章节文档转换为带章节元数据的文本块。
- 同时建立中文关键词索引和语义向量索引。
- 对用户问题进行拆分、分类、查询增强和多路检索。
- 证据不足时明确拒答，避免模型凭空补充。
- 返回回答时保留章节、原文片段等引用依据。
- 保存会话、上一轮问答、回退操作和长期学习记录。
- 控制 embedding 和回答模型的调用次数与上下文 token 消耗。

## 3. 当前不属于目标的内容

- 不把教材内容改写成脱离原文的百科知识库。
- 不在证据不足时使用大模型常识替教材作答。
- 不在当前阶段接入 Web UI、账号系统、云端部署和多人协作。
- 不把长期记忆理解成无限保存全部对话；长期记忆只保存有用的学习结构化信息。

## 4. 核心原则

### 原文优先

回答必须由检索到的教材片段支撑；引用不足时返回“知识库依据不足”。

### 可审计

每个文本块保留章节、小节、来源文件和 `chunk_id`，每次回答保存报告。

### 成本可控

优先使用本地索引、BM25 和 embedding 缓存；只把必要上下文交给回答模型。

### 可替换

embedding 和回答模型通过适配器接入，后续可以替换供应商，不把业务流程绑定到单一模型。

### 小步迭代

先保证单问题查询基本可靠，再扩展多问题、记忆、错题、Web UI 和更复杂的 Agent 能力。
