# 功能需求与验收标准

## 1. 已完成基线功能

| 编号 | 功能 | 验收标准 | 状态 |
| --- | --- | --- | --- |
| F-001 | Word 文档切分 | 208 个源文档可生成带章节元数据的 1125 个 chunk | 已完成 |
| F-002 | 关键词检索 | 输入教材术语可返回相关原文和章节 | 已完成 |
| F-003 | 向量检索 | 豆包 embedding 可生成向量并从 Chroma 返回候选片段 | 已完成 |
| F-004 | 混合检索 | BM25 和向量结果合并、去重并重排 | 已完成 |
| F-005 | 保守回答 | 证据足够才调用 DeepSeek，证据不足时拒答 | 已完成 |
| F-006 | 原文引用 | 回答保存章节、来源文件和原文片段 | 已完成 |
| F-007 | 检索自救 | 单题最多三轮检索，后续轮次优先使用 BM25 | 已完成 |
| F-008 | 成本控制 | 相同 query 命中 embedding 缓存，减少重复 API 调用 | 已完成 |
| F-009 | 多问题 | 一次输入多个问题，逐题检索并统一输出 | 已完成 |
| F-010 | 学习会话 | 可查看上一轮、回退上一轮并保存会话文件 | 已完成 |
| F-011 | 长期学习记录 | 保存问题历史和章节学习画像 | 已完成 |

## 2. 下一阶段需求

| 编号 | 功能 | 验收标准 | 优先级 |
| --- | --- | --- | --- |
| F-012 | 扩展评估集 | 至少 30 到 50 条，覆盖主要知识域，并输出 TopK 指标 | 已完成 |

| F-014 | 回退一致性 | 回退后会话、问题历史和学习画像状态一致 | P1 |

| F-017 | 错题和复习 | 能收藏问题、标记掌握程度并生成复习清单 | 候选增强，暂不立项 |
| F-018 | 本地 Web UI | 能完成提问、引用查看、会话管理和基础设置 | 候选增强，暂不立项 |

## 3. 本轮实施范围

本轮实施：F-012、F-013、F-015、F-016。

暂不实施：F-014“回退一致性”。该功能保留在后续阶段，原因是当前优先把评估、检索、正常追问、章节过滤和引用可靠性做好。

F-017 和 F-018 虽然保留在历史需求编号中，但目前不属于正式待办，具体增强方向统一见 `docs/08_优化增强能力池.md`。只有重新确认范围和验收标准后，才转为正式立项。

本轮对 F-013 的设计要求：记忆记录必须保留会话名、轮次号和来源信息，不能把长期画像直接当作不可追溯的黑盒状态。这样未来补做 F-014 时可以按有效轮次重算。

## 4. 每个新功能必须补充

- 用户要解决的具体问题。
- 输入、输出和异常情况。
- 是否调用 embedding 或回答模型，以及预计成本。
- 对现有数据结构和流程的影响。
- 最小验收用例。
- 完成后需要更新的流程图或文档。
