# 开发路线图与变更记录

## 1. 当前路线图

### 阶段一：知识库基本盘

状态：已完成。

包括源文档整理、chunk 切分、BM25、Chroma、豆包 embedding、DeepSeek 回答、引用和基础评估。

### 阶段二：智能基础版

状态：已完成主体，仍有边界待补。

包括问题理解、检索自救、证据阈值、核心术语覆盖、token 控制、query embedding 缓存、多问题、会话、回退和长期学习记录。

### 阶段三：可靠性增强

状态：核心查询和请求异常治理已完成，回退一致性继续挂起。

本轮顺序：扩大评估集 -> 优化检索排序和阈值 -> 让记忆参与追问 -> 章节过滤 -> 严格引用校验。

其中“修正回退一致性”暂不实施，作为后续待定阶段保留。

### 阶段二验收：答案可靠性评估

状态：已完成。

- 新增 31 条答案评估样例：21 条正向题、10 条拒答题。
- 增加关键点覆盖率、逐句引用校验、期望章节和拒答正确性四类自动信号。
- 增加严格引用失败后的有限修复和安全降级路径，不放行未经原文校验的模型草稿。
- 针对跨小节列表题增加小节级证据覆盖，控制普通问题的上下文和 token 成本。
- API 核心回归结果：正向答案 `20/21`，关键点覆盖 `92.1%`，引用准确率 `100%`，拒答准确率 `100%`。

### 阶段四：索引版本和健康治理

状态：已完成。

包括确定性索引版本、源文件清单、artifact 指纹、配置一致性检查、BM25/Chroma/chunks 完整性检查，以及重建前后检索指标比较。

### 阶段五：全链路请求可靠性

状态：已完成。

包括完整查询总截止时间、可重试/不可重试异常分类、进程级基础熔断，以及耗时、失败类别和 token 成本统计。

### 阶段七：稳定核心服务接口

状态：已完成。

### 产品化增强阶段（核心主线完成后）

状态：后续。

包括错题本、收藏、复习卡片、薄弱点分析和本地 Web UI。
