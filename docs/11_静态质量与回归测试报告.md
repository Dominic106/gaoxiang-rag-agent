## 6. 人工确认和剩余风险登记

1. **本地 pickle 信任边界**：BM25 是本机生成并由 manifest 指纹保护的受控 artifact。Bandit 对 pickle 的风险提示不是误报；在开放上传、多人共享或服务部署前，应改为安全可验证的序列化格式，或增加签名和严格权限。当前不影响个人本地使用。
2. **Isort/Black 格式迁移**：Isort 仍报告历史教学脚本的 import 顺序迁移；Black 当前通过项目配置暂不批量改写 `code`，避免破坏“每行代码中文讲解”的教学约定。是否进行整库格式迁移需要人工决定。
3. **向量冷缓存压测**：本轮没有为 31 题重复消耗 embedding API 做未命中冷缓存的真实向量延迟基准，避免无必要成本。进入多用户服务前需要单独预算并发压测。
4. **回退一致性**：长期画像自动重算仍按原计划暂停，属于 F-014，不是本轮核心回归失败。
5. **覆盖率收集方式**：当前 pytest 通过子进程执行教学版回归脚本，pytest-cov 只统计父进程入口，不能把结果当作业务代码真实覆盖率。后续应接入 coverage subprocess/parallel 配置，或把核心断言逐步迁移为直接 pytest 用例。
