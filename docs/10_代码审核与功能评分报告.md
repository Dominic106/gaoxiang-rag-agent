# 代码审核与功能评分报告

更新时间：2026-08-05

## 1. 审核范围

本次审核覆盖当前核心 RAG 主线：问题拆分、问题理解、BM25/向量/混合检索、证据门禁、DeepSeek 回答、严格引用、模板校验、会话记忆、请求治理、索引健康、稳定服务接口和本地文件持久化。

本次没有把 Web UI、微信小程序、错题本、复习卡和回退一致性当作当前核心缺陷；这些功能仍属于产品增强或已明确暂停的范围。

## 2. 审核结论

当前核心功能可以作为个人学习和检索的稳定基础版使用，不能直接宣称为面向大量用户的商用生产系统。核心链路已经具备原文优先、引用可追溯、证据不足拒答、异常降级和成本控制能力，但模板输出仍存在少量模型波动，服务接口目前还是本地 Python 接口，没有鉴权、HTTP 部署、并发压测和产品级观测。

上一次综合评分：**8.63/10**。本轮静态质量升级和真实 API 复核后的最新综合评分为：**8.87/10**，详细证据见 `docs/11_静态质量与回归测试报告.md`。

## 4. 本次发现并已修复

### 4.1 评估器错误解析新版报告

文件：`code/16_eval_answer_reliability.py`

- 修正“引用校验结果”和“回答模板校验结果”的区块边界，避免两个字典被拼在一起解析。
- 修正安全降级报告没有“引用依据”标题时的引用记录解析，保留章节追溯能力。
- 增加有明确语义依据的 `可能性 -> 可能/概率` 词形别名，避免正常中文表达被评估器误判。

### 4.2 并发请求标识和统计写入

文件：`code/request_governance.py`、`code/file_locks.py`

- 请求编号在稳定问题指纹之外增加每次执行的随机段，重复问题不会共享同一个追踪 ID。
- 请求统计 JSONL 使用跨进程文件锁，避免并发追加时产生交错记录。

### 4.3 会话和长期记忆的本地持久化

文件：`code/study_memory.py`

- 会话文件和长期画像读写加入文件锁。
- 损坏 JSON 会记录日志并回退为空会话或默认画像，不会让整个查询进程直接崩溃。
- 并发追加会话轮次的编号和长期问题历史已经通过 8 线程回归。

### 4.4 向量索引重建切换

文件：`code/02_build_indexes.py`

- Chroma 先写入临时目录，再切换正式目录。
- 切换失败会恢复旧索引，临时目录会清理。
- 新索引切换成功后，旧备份清理失败只记录日志，不再把已经可用的新索引误报为构建失败。

### 4.5 LangGraph 资源复用和回答结构

文件：`code/03_query_graph.py`、`code/answer_templates.py`、`code/citation_validator.py`

- 服务进程内复用已编译的 LangGraph。
- 修复回答模型漏掉模板标签时的确定性结构补齐，不改写事实和引用。
- 中性边界说明，例如“当前教材片段未明确列出”和“暂不进行代入计算”，不再被当成需要虚构引用的事实。
- 关键路径题和风险分析对比题增加高频备考覆盖约束。

## 6. 当前剩余问题

### P1：答案模板存在小概率波动（本轮已修复结构误判）

上一轮发现的 2 个对比题结构误判已修复：现在兼容 Markdown 标题和真实概念名表头，且引用安全门没有放宽。后续仍应持续增加结构化答案评估，防止新的模型格式变体触发保守降级。

### P1：回答覆盖评估仍是自动化下限

当前关键词覆盖能发现明显漏答，但不能完全判断同义表达、概念层级和教学质量。后续应增加人工抽查集或结构化参考答案比对，但不建议引入第二个大模型作为唯一裁判。

### P2：服务接口还不是生产服务

`code/rag_service.py` 已经是稳定核心入口，但尚未提供 HTTP、鉴权、用户隔离、限流、并发压测和外部监控。这些是 Web UI/微信小程序阶段的产品化工作。

### P2：embedding 并发冷缓存重复请求

文件锁已经保证缓存文件不损坏，但两个并发进程可能同时发现同一个 query 未命中，然后分别调用 embedding API。后续可加按 key 的进程内锁或跨进程去重机制；当前 CLI 使用场景影响有限。

### P2：回退一致性仍暂停

当前回退能删除上一轮会话文件，但不会自动重算长期画像和问题历史。这是已登记的 F-014，未纳入本轮实施。

### P3：静态格式迁移尚未完成

Ruff、Flake8、Mypy、Pylint、Bandit、Pytest、Black 和 Isort 已安装。Ruff/Mypy/Flake8/Pylint 错误级别门禁已通过；Isort 和 Black 对历史教学脚本的全量格式迁移仍保留人工决策，详见 `docs/11_静态质量与回归测试报告.md`。

## 7. 审核后的建议

当前核心主线可以继续作为个人学习和检索基础使用。下一步最值得做的是解决“引用正确但模板降级”的结构化输出问题，并把 31 题评估中的低覆盖题稳定到连续多次运行都通过；完成后再考虑 Web UI 和微信小程序接入。
