# 可靠学习与检索核心达成清单

## 1. 总目标

面向中国软考高级科目“信息系统项目管理师”，建立一个以官方教材为主要依据的可靠学习和检索核心：

```text
用户提问
-> 找到教材依据
-> 返回有引用的解释
-> 找不到依据时明确拒答
-> 请求异常时不胡乱回答
-> 保存必要学习记录
```

本清单只包含达到“可靠学习与检索核心”所必须完成的工作。错题本、自动出题、模拟考试、用户上传资料和微信小程序属于后续产品增强，不作为本清单的当前验收项。

## 2. 执行规则

1. 同时只推进一个未完成阶段。
2. 每个阶段都要先明确目标，再修改代码。
3. 每个阶段完成后必须执行：语法检查、模块测试、真实样例、自测复盘和文档更新。
4. 测试通过且问题修复后，才把 `[ ]` 改成 `[x]`。
5. 如果测试发现问题，不进入下一阶段，先修复当前阶段。
6. 新想法先进入 `docs/08_优化增强能力池.md`，不随意打断当前主线。

## 5. 核心完成判定

只有阶段一至阶段七全部通过，才称为：

> 可靠的学习与检索核心完成。

届时必须同时满足：

- 检索指标有足够覆盖面。
- 答案忠实度、引用准确率和拒答准确率可测量。
- 每个关键结论可以追溯到教材原文。
- 索引版本和来源清楚可审计。
- 超时和异常不会导致无限等待或胡乱回答。
- 输出结构适合备考学习。
- 核心能力已经具备稳定服务接口。
